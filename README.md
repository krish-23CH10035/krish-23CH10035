### 🌐 BitTorrent Client

A BitTorrent client engineered from scratch using modern C++.

**Highlights**

- Implemented the complete pipeline from metadata parsing to SHA-1-verified disk writes.
- Built a recursive-descent Bencode parser and encoder supporting all four Bencode data types.
- Implemented accurate `info_hash` computation.
- Created a thread-safe piece manager with rarest-first piece selection.
- Supported pipelining of 5–10 requests per peer using 16 KB blocks.
- Managed communication across 20–50+ peer connections.
- Implemented HTTP and UDP tracker protocols based on BEP 15.
- Added exponential backoff and automatic peer blacklisting after repeated failures.

**Technologies:** C++20, TCP, UDP, SHA-1, BEP 15, Multithreading, Networking
